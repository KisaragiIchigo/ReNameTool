# NovaRename

ファイル・フォルダの一括名前変換ツール。

---

## 1. 概要
**NovaRename** は、大量のファイルやフォルダの名前を一括で変換・整理できるデスクトップアプリケーションです。  
「置換」「エリア削除」「連番」「日付」「文字移動」「ケース変換」「フォルダ名付与」「拡張子変更」などのルールを自由にドラッグ＆ドロップで組み合わせてチェーン適用できる多段パイプライン、インライン文字差分表示、Windowsの衝突を防ぐ2段階リネーム、直前のリネームを取り消すUndo機能を備えています。

---

## 2. 実行・起動バッチ

- **`起動.bat`**: 開発モード / 通常起動用バッチ。ダブルクリックするだけでアプリが即座に起動します。
- **`コンパイル.bat`**: 配布用パッケージ自動生成バッチ。実行すると `Release/` フォルダ配下に以下の2種類のEXEを自動生成します：
  - **`NovaRename_Portable_1.0.0.exe`** (インストール不要の単一ポータブル実行ファイル)
  - **`NovaRename_Setup_1.0.0.exe`** (デスクトップショートカット等を作成するインストーラー版)

---

## 3. 設定ファイルの保存場所
他ツールとの競合を防ぐため、設定ファイルはプロジェクト直下の専用ディレクトリに保存されます：
- **`config/[NovaRename]config.json`**
  - ルール構成・各パラメータ
  - 過去の入力ワード履歴（検索語・置換語・削除文字・追加文字など）
  - スキャンオプション
  - ウィンドウ位置・サイズ
  - テーブル列幅・サイドバー幅

---

## 4. 主な機能

- **過去の修正ワード履歴（プルダウン選択）**:
  - 各入力欄の「▼」ボタンから過去に入力したワードをプルダウンで即座に呼び出し可能。不要な履歴は「×」で削除可能。
- **ダブルクリックでの手動編集 ＆ コピー**:
  - ファイル名をダブルクリックしてその場で手動編集可能（手動修正したファイルにも一括ルールが連動適用されます）。
  - テキスト選択・右クリックメニューによるファイル名/フルパスのコピーに対応。
- **多段パイプライン**:
  - 複数のルール（置換、連番、日付、文字移動など）をドラッグして自由な順序で組み合わせて適用可能。
- **インライン差分ハイライトとソート機能**:
  - 変更前後の名前を比較し、追加箇所（緑）と削除箇所（赤）を文字単位でプレビュー。
  - プレビューのヘッダーをクリックすることで、ファイル名、フォルダ、サイズでリストを並び替え（ソート）可能。
- **柔軟なスキャンオプション**:
  - ファイルのみ、フォルダのみ、両方を対象にできるほか、「サブフォルダを含む」場合の親フォルダ（ルート）のリネーム除外・包含を選択可能。
- **安全リネーム ＆ Undo**:
  - 大文字小文字変更やスワップ衝突を一時ファイル経由で安全に実行。
  - 誤実行時は「元に戻す」ボタンまたは `Ctrl + Z` で即座にロールバック可能。
- **リネーム後のリスト保持**:
  - リネーム実行後もファイルがリストから消えず、新しい名前に自動更新されてそのまま作業を継続可能。

## 5. 技術スタック

- **フレームワーク**: Electron + React 18 + TypeScript
- **ビルドツール**: Vite + electron-builder
- **スタイリング**: Tailwind CSS v3
- **アイコン**: lucide-react
- **アニメーション**: framer-motion
- **UIプリミティブ**: @radix-ui/react-*
- **仮想スクロール**: @tanstack/react-virtual
